# ea-python-v2

WeQuant 火币 CNY 现货教学样本（约 2014–2017 回测窗）。本仓库从 [zhy0313/ea-python](https://github.com/zhy0313/ea-python) 克隆，用于后续改造。

统一结构：`PARAMS` → `initialize` → `handle_data`。45 个 `.py` 里大约 32 套独立逻辑，另有 11 个 ETH 克隆（换标的和部分参数）。

这些脚本绑的是已停用的 WeQuant / 火币 CNY 现货 API，不能直接实盘；移植要重写 data、order、account。

## 共同模式

绝大多数是 **一根指标 → 全仓买或全仓卖**。没有仓位单元、没有成本过滤、也没有趋势/震荡切换。日线来回翻一次，佣金+滑点大约 **0.6%**，零轴类策略会先被费用吃掉。真正管仓位的只有海龟、网格、动态平衡、价值平均。

## 四类策略

**趋势（最多）**  
双均线、EMA 金叉、TEMA、DMA、MACD 零轴、DMI、阿隆、Dual Thrust、海龟、ATR/NATR 通道、MOM/ROC、BOLL 上破、BOP、EMV。单边行情能跟上，震荡里会反复打脸。其中 **EMA 带 10% 净值回撤止损**、**Dual Thrust 带 25% 账户止损**、**海龟带 ATR 头寸和加减仓**，比「MACD>0 就满仓」完整。

**震荡/回归**  
均值回归（0.9/1.2×SMA5）、RSI、CMO、CCI 穿越 ±100、KDJ 金叉死叉、W%R、AR。区间里合理，趋势里会逆势接刀。KDJ 条件最严，交易会很少。

**仓位配置（不择时）**  
网格按相对基准价调仓；动态平衡维持约 50/50；价值平均每期把市值调到目标。管的是暴露，不是方向。

**条件单（一次性）**  
计划委托、跟踪委托（文件名写成「路踪」）、止盈止损。演示下单，不是循环 EA。

## 代码和教科书对不上的地方

| 问题 | 文件 | 实际后果 |
|---|---|---|
| 用 ADX 高低当买卖方向 | `ADMI指标策略.py` | ADX 只量强度；大跌时 ADX 升高也会满仓做多 |
| NATR 当价格加减 | `NATR指标策略.py` | NATR 是百分比，通道几乎贴着现价 |
| WILLR 阈值用了 10/90 | `W&R指标策略.py` | talib 输出是 −100~0，买入条件几乎不成立 |
| 累积 AD 和 0 比 | `Chaikin指标.py` | 头寸可能整段回测都不换边 |
| 文件名「定买」、逻辑是定卖 | `价值平均定买策略.py` | 拿错文件会反向减仓 |
| ETH 残留 BTC 常量 | `ETH-RSI`、`ETH-Dual Thrust` | 最小下单或初始持仓对不上 ETH |

BOLL 在这批代码里是 **上轨买、下轨卖**（突破），不是回归。`bbands_opt_width_m=60` 取了数据但没参与判断。

海龟是仓库里最接近完整交易系统的一份：唐奇安入场、T/2 离场、0.5ATR 加仓（最多 4 单位）、2ATR 止损、头寸 = 净值 1%/ATR。ATR 对窗口做简单平均，且第一根 TR 会环绕用到 `close[-1]`，头寸会偏。

## 若只留几份继续改

- **趋势**：`海龟策略.py` 或 `Dual Thrust策略.py`
- **震荡**：`KDJ指标策略.py` 或 `均值回归策略.py`，并加 ADX 一类体制过滤
- **配置**：`动态平衡策略.py` / `网格交易策略.py` 当仓位层，不要再叠一个全仓指标开关

## 逐策略对照

质量标签：**可用骨架** = 逻辑自洽可改；**教学模板** = 能跑但过简；**指标误用 / 实现有坑** = 先修再谈回测。

## ETH 克隆注意

11 个 ETH 文件只换标的、佣金、部分窗口。逻辑与 BTC 同名文件一致。

- `ETH-Dual Thrust` 的 PARAMS 仍初始化 `huobi_cny_btc`
- `ETH-RSI` 最小下单常量仍是 `HUOBI_CNY_BTC_*`
- ETH 网格卖出档拉到 1.2–1.8，比 BTC 的 1.05–1.2 宽很多，牛市会拿得更久

依据仓库源码静态阅读，无回测净值。
